# VoiceMate · 使用说明

一个文件夹搞定：语音服务、中文界面，还**自带 Python**。**双击 `启动.bat` 就能用**。

```
Breeze语音工坊-分享版\
├─ 启动.bat                 ← 双击这个（唯一要点的东西）
├─ app\
│  ├─ 启动.bat
│  ├─ server.py             后端：管进程、转发接口、存方案、麦克风桥接
│  ├─ web\                  界面（index.html / style.css / app.js）
│  ├─ bin\                  breeze-server.exe 等程序和 VirtualMicPlayer.exe
│  ├─ models\               模型（3.3 GB）
│  ├─ voices\               角色库（*.breeze）
│  └─ data\                 气泡 / 提示词方案 / 预设文本
└─ runtime\                 自带的 Python，不用另装
```

**分享版是干净的**：没有角色、没有提示词方案、没有预设文本；
「情绪标记」的 `[笑]` `[大哭]` `[叹气]` 等 15 个中括号标签，以及「提示词 / 语气指令」下的语速、语气、情绪、状态四组气泡都保留着。

---

## 一、怎么用

双击 **`启动.bat`**，会弹出一个黑窗口，然后：

1. 第一次要等 **30～90 秒**（加载 3.3 GB 模型 + 预热），窗口里会打印等待信息；
2. 就绪后浏览器自动打开 <http://127.0.0.1:8099/>；
3. 关掉那个黑窗口 = 停止全部（服务和界面一起退出）。

> 如果 8080 端口上**已经有别的程序在跑语音服务**，本程序会直接复用它，不会去重启它。

---

## 二、五个页面

顺序就是按日常使用频率排的。

### ① 开始配音（默认页）

左边选角色 → 该角色的**提示词方案**会列出来 → 点一条就把提示词、引导强度、种子填好（**不会动正文**）。

右边写好文字，点 **生成语音**，**边合成边播放**：首包一般 0.5 秒就到，听到第一句就开始出声，不用等整段生成完。生成完点一下 **保存语音文件** 就存成 wav。

- 没选角色时是「纯音色设计」，声音完全由提示词决定，不需要参考音频。
- **正文打开时是空的**，可以自己写；正文下面是**预设文本气泡**，点一下直接套用整段文本。
- 左边「选择角色」卡片里、提示词方案下面，还有一块可展开的 **「长文断句」**：把整段台词粘进去（一行一句），
  会拆成一列句子气泡；勾选或用 ⇅ 选范围后，选中的句子会**直接写进右边的「正文」**，再用同一套参数生成即可。
  默认收起，点右上角「展开」；贴进去的长文本会存在浏览器本地。

- 预设文本下面还有一行**情绪标记**气泡（`[笑]` `[大哭]` `[叹气]` `[哽咽]`…）。点一下会**插到正文的光标位置**，它属于被朗读的文本，不是提示词。例如：

  ```
  [大哭]我把之前总是喜欢[大哭]和我分享日常的那个女孩弄丢了
  ```

  共 15 个：笑、大笑、大哭、抽泣、哽咽、叹气、咳嗽、清嗓子、惊讶、尖叫、喘息、低语、停顿、颤抖、咬牙。
  光标在中间就插在中间，选中一段再点会把它替换掉；没点进文本框就追加到末尾。
- **存为预设文本** 把当前正文存进全局文本库，所有角色都能用。
- **保存语音文件** 在最下面「保存语音」里，生成完点一下就能存成 wav；
  文件名是 `角色名_句子前8个字…`，例如 `xxmm_夜色落下来的时....wav`，没选角色时用 `无角色`。
- **停止预览**：只把正在播的声音掐掉，生成继续跑，跑完照样能保存；
- **停止生成**：连生成一起停，停完可以**立刻**重新点「生成语音」，不用等上一段收尾。

#### 语速 / 语气 / 情绪 快捷词

提示词输入框下面是四行**可点的气泡**，一共 36 个：

| 行 | 气泡 | 选法 |
| --- | --- | --- |
| 语速 | 很慢 · 偏慢 · 偏快 · 很快 | **互斥**，只能有一条 |
| 语气 | 温柔 · 认真 · 耳语 · 撒娇 · 冷淡 · 俏皮 · 热情 · 恳求 | 可多选 |
| 情绪 | 开心 · 平静 · 得意 · 期待 · 难过 · 生气 · 厌恶 · 无奈 · 失望 · 惊讶 · 激动 · 焦虑 · 羞愧 · 嫉妒 · 烦躁 | 可多选 |
| 状态 | 正在哭泣 · 受委屈 · 疼痛 · 恐惧 · 疲惫 · 强忍 · 醉酒 · 刚睡醒 · 生病 | 可多选 |

每组里的气泡都能在「预设管理 → 提示词气泡」里增删改。

每个气泡写进去的不是一个词，而是一整句细致的描述。例如点「疲惫」会追加：

> 气息短而浅，语速拖沓，吐字有点含糊，句尾几乎没有力气抬起来。

点「生气」：

> 压低嗓音，气息变重，咬字用力，语速偏快且句子短促，像在克制着怒意。

点「正在哭泣」：

> 声音带着明显的哭腔，气息一抽一抽的，句子被抽泣打断，字尾发颤，越说越说不下去。

- **点一下**追加到提示词末尾，气泡变蓝表示已选中；
- **再点一下**取消，会把它从提示词里删掉；
- 语速互斥（点新的自动替换旧的），语气和情绪可以任意叠加；
- 旁边的 **清空** 一键清掉全部提示词。

这些词对所有角色通用，与角色本身无关。

### ② 创建角色

上传一段 5～15 秒的参考音频 + 它的**逐字文本**（必须一字不差），填个英文名字保存，就成了音色库里的角色。

### ③ 随机音色

点「随机一个音色」从内置的 12 条描述里抽一条，试听满意就「用到开始配音」，也可以直接改。

### ④ 音色库

每个角色都能：改描述（改完点保存）、查看参考文本、**删除**（会连 `.breeze` 文件一起删）。

### ⑤ 预设管理

「预设管理」这一个标签页里放了三块，都在这里改。

三块默认都是**收起**的，收起时只露第一条，点右上角「展开」才看全部；再点「收起」收回去。

#### ① 提示词气泡

「开始配音」里那四行气泡（语速 / 语气 / 情绪 / 状态，共 22 条）就是这里的内容。

每条可以改两个字段：

- **标签**：气泡上显示的字，比如 `很慢`
- **提示词**：点这个气泡时追加到提示词框里的整句描述

每个组还能：

- 改组名（直接改左边那个输入框）
- 勾选 **互斥**：这组同类只能选一条（语速就是互斥的，语气/情绪/状态可以叠）
- **＋ 加一条** 往组里加新气泡
- **删整组** 把这组整个删掉

底部：

- **保存气泡**：真正写进 `data\chips.json`，首页气泡立刻变
- **＋ 加一组**：新建一个分组
- **还原未保存的改动**：把没保存的编辑丢掉

> 改完不点保存是不会生效的，页面重新加载也会丢。

#### ② 提示词方案

每条方案都能：使用、**编辑**、删除、以及勾选「共用」。
标题就是「开始配音」左侧列表里显示的那个名字，方案只存提示词和参数，**不存正文**。

点 **编辑** 会在这一条下面**直接展开**（不弹窗），可以改：

- **标题**
- **提示词正文**（多行）
- **引导强度**（1～4，带一位小数）
- **随机种子**

改完点 **保存修改** 立即生效；点 **取消** 收起并还原改动。

每条方案后面还有个 **☑ 共用** 勾选框：

- 不勾：只有**它所属的角色**能看到；
- 勾上：**所有角色**都能用，左侧列表会带一个绿色「共用」小标签。

#### ③ 预设文本

这里存的正文**所有角色共用**，可新建、编辑、删除。
在「开始配音」里，正文下方会以气泡形式列出来，点一下就能套用。

## 三、数据存在哪

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 提示词气泡 | `data\chips.json` | 语速/语气/情绪/状态四组气泡的标签和描述 |
| 提示词方案 | `data\presets.json` | 只有提示词和参数，没有正文 |
| 预设文本 | `data\texts.json` | 全局共用，和角色无关 |
| 角色 | `voices\*.breeze` | 二进制，约 800 字节/秒参考音频 |
| 生成历史 | 不保存 | 只在内存里，刷新页面就没了 |

> 如果 8080 上是**别的程序**起的服务，角色实际读写的是那个程序自己的 voices 目录（通常是上一级的 `..\voices`）。本程序删除角色时会两个目录都找一遍。

## 四、排错

| 现象 | 处理 |
| --- | --- |
| 双击没反应 / 闪一下就没了 | 看看 `runtime\python.exe` 是否被杀毒软件删了；窗口里会写明 |
| 一直停在「等待模型加载」 | 看那个黑窗口里的输出，或 `app\breeze-server.log`；显存被占满时加载会失败（重启电脑最省事） |
| 页面打开是空白 | 地址要用 8099，别用 8080（8080 是纯接口） |
| 生成报 404 unknown voice | 这个角色对应的 `.breeze` 不在当前服务的 voices 目录里 |
| 改了界面没生效 | Ctrl+F5 强刷 |

## 五、搬家 / 卸载

整个文件夹可以随便拷到别的位置、别的电脑（路径没有写死），拷的时候保持目录结构不变就行。
不想要了，直接删掉整个文件夹即可，不会往系统里装任何东西（只有虚拟声卡 CABLE 是单独装的驱动）。

第一次运行时 Windows 可能会弹「已保护你的电脑」或防火墙提示，允许就行；它只监听本机 `127.0.0.1`，不对外网开放。

需要一块能跑 Vulkan 的显卡（NVIDIA / AMD / Intel 核显都行），显存建议 6 GB 以上；模型是 Q8_0 量化版，约 3.3 GB。
